# Права

[English](permissions.md) · **Русский** · [Содержание](README.ru.md)

Своей системы прав у аддона нет. Без [AcuaTARDISGadgets](https://modrinth.com/mod/acuatardisgadgets) выращивать помещения и настраивать интерфейсы в ТАРДИС может любой, кому можно там строить.

## С AcuaTARDISGadgets

Нужен AcuaTARDISGadgets 1.20.1-1.0.6 или новее, на Forge или Fabric. Его **Security Manager** показывает права ТАРДИС, и аддон добавляет в этот список три своих (только для ТАРДИС Tardis Refined):

| Право | Что разрешает |
|---|---|
| **Выращивать помещения** | Открывать каталог помещений у узла роста и выращивать из него новое помещение или коридор |
| **Управлять помещениями** | Открывать меню помещения у его блока управления, заменять, удалять (в том числе **Удалить всё**) и переименовывать помещение |
| **Настраивать интерфейсы** | Ставить и ломать интерфейс ТАРДИС, открывать его меню, снимать его ключом или переключать ключом стороны, вставлять ID отвёрткой или картой памяти AE2 |

- Для интерфейса снаружи, у оболочки, право проверяется в ТАРДИС этой оболочки.
- Игрок без права видит сообщение над хотбаром: меню не открывается, интерфейс не ставится, ничего не меняется. С `debug = true` отказ пишется ещё и в лог.
- Сервер сам сообщает каждому игроку, что ему нельзя, поэтому клиент знает это без запросов. После того как право выдали или забрали в Security Manager, это вступает в силу в течение секунды. Что бы ни думал клиент, каждое действие сервер всё равно проверяет сам.
- Копировать ID интерфейса (отвёрткой или картой памяти) можно без прав: это только чтение.

### Когда права начинают действовать

AcuaTARDISGadgets оставляет ТАРДИС открытой для всех, пока в ней не включена защита. Она включается, когда игрок впервые использует там Security Manager, и этот игрок получает все права, включая права аддона. После этого остальным доступно только то, что им выдали в Security Manager.

Если защиту в ТАРДИС включили **до** установки аддона, прав аддона там пока нет ни у кого, даже у владельца. Игрок, которому можно менять права (у включившего защиту такое право есть), выдаёт их в Security Manager, в том числе себе.

## Как выключить

`compat.acuaTardisGadgets = false` в `config/tardis_rooms/common.toml` (см. [Настройки](configuration.ru.md)). Тогда аддон вообще не добавляет свои права в AcuaTARDISGadgets, и строить могут все, как без этого мода. Параметр читается один раз при запуске игры: после изменения перезапустите игру (или сервер).

На сервере значение должно совпадать на сервере и у всех клиентов: AcuaTARDISGadgets передаёт права по сети номером в своём списке, и если параметр с разных сторон разный, Security Manager может показать или изменить не те права.
