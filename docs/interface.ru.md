# Интерфейс ТАРДИС

[English](interface.md) · **Русский** · [Содержание](README.ru.md)

Интерфейс ТАРДИС передаёт ресурсы между связанными интерфейсами: между помещениями или между интерьером и миром снаружи, у оболочки ТАРДИС.

## Установка

- Внутри ТАРДИС интерфейс ставится где угодно.
- Снаружи — только вплотную к оболочке ТАРДИС: в пределах блока от неё или на блок ниже, если оболочка высотой в два блока. Тогда он принадлежит этой ТАРДИС. Рядом с оболочками двух разных ТАРДИС он не работает (конфликт сети).
- Интерфейс работает, только пока загружен его чанк.

## Связь

Интерфейсы одной ТАРДИС с одинаковым ID связаны, как туннели P2P в Applied Energistics 2. ID — четыре шестнадцатеричных символа, например `0A29`.

- **Создать ID** в меню интерфейса даёт новый ID, которого нет ни у одного интерфейса этой ТАРДИС.
- ID принадлежит ТАРДИС, в которой создан. Интерфейс с ID другой ТАРДИС не подключается.
- Состояние интерфейса видно в его меню и в Jade:

| Состояние | Что значит |
|---|---|
| Подключено | связан с остальными интерфейсами с этим ID |
| Нет ID | связывать пока не с чем |
| Отключено: ID другой ТАРДИС | ID создан в другой ТАРДИС |
| Отключено: рядом нет оболочки | вне ТАРДИС, а оболочки рядом нет (например, ТАРДИС улетела) |
| Отключено: конфликт сети | рядом оболочки двух и более ТАРДИС |

## Меню интерфейса

Нажмите на интерфейс звуковой отвёрткой, в любом её режиме:

- состояние, ID и число связанных интерфейсов;
- **Создать ID**, **Вписать ID из отвёртки**, **Очистить ID**;
- **Направление**: вход, выход или вход и выход;
- что интерфейс передаёт — каждое включается и выключается;
- **Настройка сторон** — объёмный вид интерфейса с соседями;
- подсказки.

## Направление

- **Вход** принимает: всё, что в него подают трубы и механизмы, уходит соседям связанных интерфейсов с выходом.
- **Выход** отдаёт: трубы и механизмы забирают из него то, что лежит у соседей связанных интерфейсов со входом.
- **Вход и выход** — и то и другое.

Интерфейс ничего не хранит и сразу передаёт всё дальше, поэтому скорость зависит от подключённых труб и механизмов. Связанные интерфейсы, стоящие рядом, друг другу не передают, чтобы ничего не ходило по кругу.

## Что передаёт

| Вид | Загрузчики | Примечание |
|---|---|---|
| Предметы | NeoForge, Fabric | |
| Жидкости | NeoForge, Fabric | |
| Энергия | NeoForge, Fabric | На Fabric нужен Team Reborn Energy — он есть почти во всех модах техники для Fabric |
| Редстоун | NeoForge, Fabric | см. ниже |
| Химикаты | NeoForge | Mekanism |
| Сеть ME | NeoForge | Applied Energistics 2, см. ниже |

**Редстоун.** Самый сильный сигнал рядом со связанными интерфейсами со входом выдают связанные интерфейсы с выходом. Интерфейс «вход и выход» только принимает сигнал — иначе он поймал бы свой же сигнал и защёлкнулся навсегда.

**Сеть ME.** Объединяет сети ME рядом со связанными интерфейсами в одну, как квантовый мост, в обе стороны независимо от направления. Карта памяти AE2 копирует ID интерфейса и вписывает его в другой интерфейс.

## Стороны

У каждой стороны свой режим:

| Режим | Что делает |
|---|---|
| По умолчанию | сторона сама ничего не делает; трубы и механизмы подают и забирают как обычно |
| Вставлять | интерфейс кладёт в соседа с этой стороны то, что есть у связанных интерфейсов со входом. Нужен выход |
| Забирать | интерфейс вынимает из соседа с этой стороны и отправляет связанным интерфейсам с выходом. Нужен вход |
| Выключено | стороны для соседа нет: трубы, кабели ME и редстоун её не видят, а связанные интерфейсы не берут блок рядом с ней |

«Вставлять» и «Забирать» работают с обычными сундуками, без труб. Они срабатывают раз в 4 тика: стопка предметов, до 16 вёдер жидкости или химиката или столько энергии, сколько примут.

Как настроить стороны:

- **Настройка сторон** в меню: левый клик — следующий режим, правый — предыдущий, Shift + клик — по умолчанию; блок вращается перетаскиванием; соседние блоки можно показать или скрыть;
- **ключ любого мода**: правый клик по стороне переключает её режим.

## Отвёртка

У звуковой отвёртки два режима, они переключаются Shift + колёсиком мыши, когда отвёртка в руке:

- **Обычный** — отвёртка работает как в Tardis Refined. Правый клик по интерфейсу открывает его меню.
- **Настройка** — собственные действия отвёртки Tardis Refined отключены, а вместо них отвёртка переносит ID интерфейсов:
  - Shift + правый клик по интерфейсу запоминает его ID;
  - Shift + левый клик по интерфейсу вписывает запомненный ID;
  - Shift + правый клик в воздух забывает его.

Блоки этого аддона (узлы роста, блоки управления, заглушки) отвечают на отвёртку в обоих режимах. Режим и запомненный ID видны в подсказке отвёртки.

## Ключи

- Правый клик переключает режим стороны, по которой кликнули.
- Shift + правый клик снимает интерфейс сразу в инвентарь вместе с настройками.

Ключи определяются по метке предметов `tardis_rooms:wrenches`: общие метки ключей плюс ключ Tech Reborn. Датапак может её дополнить.

## Настройки переносятся с блоком

Сломанный или снятый интерфейс помнит свои настройки: ID, направление, виды и стороны. Чтобы сбросить их, положите интерфейс в сетку крафта.

## Jade

С Jade в подсказке видно состояние интерфейса, его ID, стороны не в режиме «по умолчанию», а при подключении — число связанных интерфейсов, направление и что он передаёт. Полоса энергии показывает энергию в хранилищах рядом со связанными интерфейсами. Настройка `compat.jade` это отключает.
