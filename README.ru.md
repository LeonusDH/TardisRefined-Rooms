# TARDIS Refined: Rooms

[English](README.md) · **Русский**

Аддон для [Tardis Refined](https://github.com/Whocraft/TardisRefined) на Minecraft 1.20.1 (Forge и Fabric). Вместо бесконечных процедурных ARS-коридоров интерьер ТАРДИС строите вы сами, помещение за помещением.

Полная документация: [docs](docs/README.ru.md).

## Возможности

### Рост интерьера

- Интерьер разбит на сетку модулей на пяти этажах: этаж хаба, три под ним и один над ним.
- В переходах стоят **узлы роста**. Нажмите на узел звуковой отвёрткой, и откроется каталог помещений и коридоров. Выберите вариант, и ТАРДИС вырастит его за стеной. Рост бесплатный.
- В каталоге есть план каждого варианта сверху и **карта этажа**: что уже занято, где хаб, где строить нельзя и куда встанет новое помещение.
- У каждого помещения есть **блок управления помещением**. Через него отвёрткой помещение можно переименовать, заменить или убрать. Помещение не уберётся, если через него связаны другие помещения.
- Убрать помещение мешают и ваши вещи внутри: контейнеры или механизмы, которые вы поставили или заполнили. Нетронутые блоки, пришедшие вместе с помещением, не мешают. Аддон называет, что мешает, обводит это сквозь стены и всё равно может убрать помещение вместе с этим после отсчёта в 10 секунд. См. [Помещения](docs/rooms.ru.md).
- Переход, который никуда не ведёт, закрывает **заглушка прохода**. Если соседнее место освободится, заглушка станет новым узлом роста.
- Датапаки могут добавлять свои помещения, а любое построенное помещение можно сохранить как такое. См. [Помещения из датапаков](docs/datapack-rooms.ru.md).
- С AcuaTARDISGadgets его Security Manager решает, кому в ТАРДИС можно выращивать помещения, управлять ими и настраивать интерфейсы. См. [Права](docs/permissions.ru.md).

### Интерфейс ТАРДИС

Блок, который передаёт ресурсы между связанными интерфейсами: между помещениями или между интерьером и внешним миром рядом с оболочкой.

- Интерфейсы с одинаковым ID связаны. Отвёрткой можно скопировать ID с одного интерфейса и вставить в другой.
- У интерфейса есть направление (вход или выход) и выбор, что он передаёт: предметы, жидкости, энергию, редстоун, химикаты Mekanism (только на Forge) и сеть ME из AE2.
- Интерфейс ничего не хранит и передаёт всё сразу, поэтому скорость зависит от подключённых труб и механизмов.
- Каждую сторону можно перевести в режим **«По умолчанию»**, **«Вставлять»**, **«Забирать»** или **«Выключено»**. Это делается в объёмном окне настройки сторон или ключом из любого мода. Стороны «Вставлять» и «Забирать» работают с обычными сундуками, без труб. Выключенная сторона ничего не принимает и не отдаёт: трубы, кабели ME и редстоун её не видят, а блок рядом с ней связанные интерфейсы не используют.
- Shift + ПКМ ключом снимает интерфейс сразу в инвентарь вместе с настройками.
- Ключи определяются по тегу предметов `tardis_rooms:wrenches`: в него входят общие теги ключей и ключ Tech Reborn. Сборка может добавить свои ключи датапаком.

Подробнее — на странице [Интерфейс ТАРДИС](docs/interface.ru.md).

### Другие изменения в Tardis Refined

- Процедурные ARS-комнаты и коридоры отключены, в том числе случайные коридоры над хабом.
- Хаб TR упрощён: остаются центр со шлюзом, смотровая Ока Гармонии и два коротких перехода к первым узлам роста. Остальное становится местом для строительства. Это происходит только в хабе, где ещё никто ничего не строил.
- У внутренних дверей и высоких оболочек ТАРДИС появляется невидимая верхняя половина: на верх двери можно навести прицел и нажать, и туда нельзя поставить блок.

## Требования

| | Forge | Fabric |
|---|---|---|
| Minecraft | 1.20.1 | 1.20.1 |
| Загрузчик | Forge 47 или новее | Fabric Loader 0.15 или новее, Fabric API 0.92 или новее |
| Tardis Refined | 2.1.7 или новее | 2.1.7 или новее, сборка для Fabric |
| Forge Config API Port | — | 8.0 или новее (вложен в Tardis Refined) |

Необязательная совместимость. Каждая включается, только если установлен соответствующий мод:

| Мод | Forge | Fabric | Что даёт |
|---|---|---|---|
| Mekanism 10.4+ | ✓ | — | Химикаты через интерфейс |
| Applied Energistics 2 15+ | ✓ | ✓ | Сеть ME через интерфейс; картой памяти можно копировать и вставлять ID интерфейса |
| Jade 11+ | ✓ | ✓ | Состояние интерфейса во всплывающей подсказке |
| Team Reborn Energy 3+ | — | ✓ | Энергия через интерфейс. Его вкладывают в себя большинство технических модов на Fabric; на Forge энергия работает и так |
| AcuaTARDISGadgets 1.0.6+ | ✓ | ✓ | Права выращивать помещения, управлять ими и настраивать интерфейсы в его Security Manager, см. [Права](docs/permissions.ru.md) |

Поддержку Mekanism, AE2, Jade и AcuaTARDISGadgets можно выключить в настройках.

## Свои помещения через датапак

Датапак может добавить в каталог свои помещения: один или два шаблона структуры и JSON-файл на помещение. Любое построенное помещение можно сохранить таким датапаком командой `/tardis_rooms export <id>`. Готовый пример лежит в [`examples/datapack`](examples/datapack/README.ru.md). JSON помещения, требования к шаблону и экспорт описаны на странице [Помещения из датапаков](docs/datapack-rooms.ru.md).

## Настройки

Настройки лежат в `config/tardis_rooms/common.toml`. Там отключаются процедурные помещения Tardis Refined и упрощение хаба, включаются отладочный лог и отдельные совместимости. Блоки, которые никогда не мешают убрать помещение, перечислены в отдельном файле `config/tardis_rooms/removable_with_room.toml`. Все параметры и команды описаны на странице [Настройки и команды](docs/configuration.ru.md).

## Сборка

Нужен JDK 21. Tardis Refined, Mekanism, AE2, Jade, Team Reborn Energy, AcuaTARDISGadgets и Architectury API Gradle скачает из Maven сам:

```sh
./gradlew build
```

Jar появятся в `forge/build/libs/` и `fabric/build/libs/`. На Windows то же самое делает `build.bat`: он сам находит JDK 21 и пишет вывод в `build.log`.

Общий для обоих загрузчиков код лежит в `common/`; в `forge/` и `fabric/` — только то, что у них отличается.

Код интерфейса в `common/.../iface` от Tardis Refined не зависит. То, что он передаёт (энергия, предметы, жидкости, химикаты, ME, редстоун), — записи внутреннего реестра (`iface/kind`), у каждой своя часть в каждом интерфейсе. Всё, что касается ТАРДИС, — какие интерфейсы связаны и отвёртка, — в `iface/tardis`.

Проверка прав идёт через `room/RoomPermissions`, где по умолчанию разрешено всё; `room/RoomPermissionSync` сообщает каждому клиенту, что ему нельзя, чтобы меню не открывались. Совместимость с AcuaTARDISGadgets подключается к ней из `compat/acua`; больше ничего от этого мода не зависит.

### Тесты

- `./gradlew :common:test` — тесты кода (игра не нужна).
- `./gradlew :forge:runGameTestServer` и `./gradlew :fabric:runGameTestServer` запускают сервер без окна, проходят игровые тесты (интерфейсы и помещения) и выходят. Упавший тест — ошибка задачи. Тест жидкостей с котлом — только на Fabric: на Forge 1.20.1 ванильный котёл не отдаёт жидкость другим модам.

На GitHub сборка идёт на каждый пуш, а тесты — по запросу: Actions → Tests → Run workflow, все или один набор.

> [!NOTE]
> Java считает `!` в пути разделителем внутри путей к jar, поэтому, если в пути к папке проекта есть `!`, игра (датаген, тестовые запуски) не запускается. `build.bat` обходит это, подключая папку как временный диск; если запускаете Gradle вручную, используйте путь без `!`.

Английский перевод генерируется из `TRoomsText` командой `./gradlew :forge:runData`. Остальные языки — обычные файлы в `common/src/main/resources/assets/tardis_rooms/lang/`.
