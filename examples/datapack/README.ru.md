# Пример помещения из датапака

*[English version](README.md)*

`tardis_rooms_example` добавляет одно помещение — «Library» (библиотеку): книжные полки вдоль стен и кафедра посередине. Скопируйте папку в `datapacks` мира и выполните `/reload`. Библиотека появится среди комнат в каталоге узла роста.

```
tardis_rooms_example/
├── pack.mcmeta
└── data/example/
    ├── structure/rooms/library.nbt          шаблон: один модуль, 24×24 блока
    └── tardis_rooms/rooms/library.json      описание помещения
```

## library.json по полям

```json
{
  "name": "Library",
  "description": "Bookshelves along the walls and a lectern in the middle",
  "group": "room",
  "structure": "example:rooms/library",
  "entrance": {"x": 0, "z": 0, "side": "south"},
  "exits": [{"x": 0, "z": 0, "side": "north"}],
  "control_block": [11, 1, 15],
  "removable": [[11, 2, 11], "minecraft:player_head{profile:{name:\"MHF_Question\"}}"]
}
```

- `name`, `description` — название и подсказка в каталоге.
- `group` — группа каталога, здесь та же, что у встроенных комнат.
- `structure` — шаблон, `data/example/structure/rooms/library.nbt`.
- `entrance` — помещение растёт от узла через южную стену своего единственного модуля (`x` 0, `z` 0). Помещение поворачивается так, чтобы эта сторона смотрела на узел.
- `exits` — ещё один проход, в северной стене. Он станет узлом роста, соединится с проходом соседа или закроется заглушкой.
- `control_block` — блок управления стоит в x 11, y 1, z 15 шаблона, в полу в четырёх блоках к югу от кафедры.
- `removable` — блоки, которые уходят вместе с помещением, что бы в них ни было, и поэтому не мешают его убрать:
  - `[11, 2, 11]` — кафедра посередине. Без этой отметки книга, оставленная на кафедре, помешала бы убрать помещение. Кафедру, поставленную игроком в другом месте, по-прежнему придётся сначала опустошить.
  - `"minecraft:player_head{profile:{name:\"MHF_Question\"}}"` показывает второй вид записи: любая голова-вопрос в этом помещении, где бы она ни стояла. В библиотеке таких нет, запись здесь только для примера.

Все поля, требования к шаблону и запись для `removable` описаны в основном [README](../../README.ru.md#свои-помещения-через-датапак).
