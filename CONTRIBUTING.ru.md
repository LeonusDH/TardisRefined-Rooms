# Участие в разработке

[English](CONTRIBUTING.md) · **Русский**

Сообщения об ошибках, идеи и pull request'ы приветствуются. Здесь описано, как пишутся коммиты в этом репозитории: простые и прозрачные правила, чтобы историю было легко читать.

## Коммиты

Репозиторий следует [Conventional Commits](https://www.conventionalcommits.org/ru/). Коммиты, сделанные до появления этих правил, сохраняют свои исходные сообщения.

**Основные правила:**

1. Сообщения коммитов пишутся на английском.
2. Обязательно должен быть указан тип.
3. Повелительное наклонение, не прошедшее время: `add`, а не `added`.
4. Описание начинается со строчной буквы, в конце нет знака препинания.
5. Длина первой строки не должна превышать 100 символов.

**Структура:**

```
<тип>(<область>): <описание>

<подробности: необязательно, что и зачем>
```

Область необязательна, её можно не указывать, если изменение затрагивает несколько частей. Изменение, ломающее совместимость (миры, датапаки, конфиг, сеть), отмечается `!` после типа или области: `feat(config)!: rename the removable list option`.

| Тип | Значение | Пример |
| --- | -------- | ------ |
| **feat** | Новая возможность | `feat(iface): add the disabled side mode` |
| **fix** | Исправление ошибки | `fix(rooms): keep untouched template chests from blocking removal` |
| **refactor** | Изменения кода без изменения поведения | `refactor(iface): move storage kinds onto the kind registry` |
| **perf** | Производительность | `perf(iface): cache neighbour storages per side` |
| **docs** | Документация, README, комментарии | `docs: describe datapack room exports` |
| **style** | Форматирование и опечатки в коде, без изменения логики | `style(client): fix indentation in the room screen` |
| **test** | Тесты | `test(rooms): cover doorway strip mirroring` |
| **build** | Gradle, зависимости, версии | `build: bump the version to 1.3.0` |
| **ci** | GitHub Actions | `ci: run game tests on demand` |
| **chore** | Всё, что не подходит к предыдущему | `chore: update the example datapack` |

| Область | Что затрагивает |
| ------- | --------------- |
| `rooms` | Рост, управление и удаление помещений |
| `iface` | Интерфейс ТАРДИС и виды передачи |
| `compat` | Совместимость с другими модами |
| `config` | Файлы и опции конфига |
| `client` | Окна, отрисовка, клиентский код |
| `net` | Сетевые пакеты |
